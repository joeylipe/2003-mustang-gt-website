# 2003 Ford Mustang GT — Interactive Reference Website

An AI-assisted web development project created as part of a Handshake AI Skills Studio activity. Developed with [v0](https://v0.dev), published through [Vercel](https://vercel.com), and maintained using [GitHub](https://github.com).

## Overview

This project is a one-page interactive reference website dedicated to the 2003 Ford Mustang GT. It brings together vehicle specifications, factory paint colors, equipment information, and an interactive exploration of the 4.6L SOHC 2-valve V8 engine in a modern, responsive interface.

The website was created using AI-assisted development, with prompts guiding the initial design and subsequent refinements. The project also provided practical experience with website publishing, source code management, and version control.

## Features

- **Vehicle specifications:** Reference information about the 2003 Ford Mustang GT.
- **Factory paint colors:** Explore original paint color options through individual color swatches.
- **Interactive engine explorer:** A 2D visualization focused on the 4.6L SOHC 2-valve V8 engine.
- **Factory options:** Organized information about vehicle equipment and features.
- **Responsive design:** Layouts adapted for desktop and mobile screens.
- **Custom visual design:** Dark backgrounds, clear typography, and blue accents.
- **Interactive elements:** Explore vehicle information through an interface designed to be engaging and easy to navigate.

## Tools and Technologies

- **v0:** AI-assisted website generation, prompt-based iteration, and design refinement.

- **Web technologies:** The languages and frameworks used in the implementation can be found in the repository's source files.

## Development Workflow

The project followed an iterative AI-assisted development workflow:

1. **Define the concept:** Describe the website's purpose, visual direction, and key features.
2. **Generate the initial site:** Use v0 to turn the written description into a working web interface.
3. **Review and refine:** Evaluate the generated website and use targeted prompts to improve the design, functionality, and mobile experience.
4. **Publish the website:** Make the website accessible through Vercel.
5. **Connect GitHub:** Push the project source code to a GitHub repository.
6. **Make and publish a change:** Refine an existing element, push the updated code, and verify the change in the published website.

This process demonstrates how AI-assisted tools can support website development while allowing the developer to guide decisions, review generated results, and make improvements.
